## 板材端
### 1、板材在基础算法矫正后根据视觉数据库映射关系校色。
```powershell
python board_photo_match_v6_roi_crop.py `
>> --photo data/bancai/P278c.jpg `
>> --standard data/standard_chart.png `
>> --library output_combined/glue_visual_library.csv `
>> --mapping output_combined/visual_mapping_T_poly2/visual_mapping_T.json `
>> --out board_match_combined `
>> --top-k 10 `
>> --board-display-l-offset -3.0 `
>> --board-display-chroma-scale 0.95 `
>> --board-display-chroma-offset -1 `
>> --board-display-a-offset -2 `
>> --board-display-b-offset 4
```
### 2、板材校色后将roi的颜色扩展至整个板子的颜色
```powershell
python apply_board_display_to_full_region.py `
>> --image board_match_combined\02_board_corrected.png `
>> --out board_match_combined\08_full_display_adjusted.png `
>> --board-display-l-offset -3 `
>> --board-display-chroma-scale 0.95 `
>> --board-display-chroma-offset -1 `
>> --board-display-a-offset -1 `
>> --board-display-b-offset 5.5 `
>> --force-select-region
```
### 3、尝试色貌模型，将LAB参数改为色貌学参数映射关系
```powershell
python cam16ucs_project_tools.py add-library `
>> --library output_combined\output_combined\glue_visual_library.csv `
>> --out output_combined\output_combined\glue_visual_library_cam16ucs.csv
```

### 4、用色貌学进行校色显示
```powershell
python render_cam16ucs_appearance_view.py `
>> --image board_match_combined\02_board_corrected.png `
>> --out board_match_combined\09_cam16ucs_appearance_view.png `
>> --j-offset -3 `
>> --chroma-scale 0.95 `
>> --chroma-offset -1 `
>> --ap-offset -3 `
>> --bp-offset 5.5 `
>> --force-select-region
```

## 胶块端
### 1、进行胶块的选择与基础算法矫正
```powershell
python manual_visual_dataset_builder.py `
>> --photo data/spoo2.jpg `
>> --standard data/standard_chart.png `
>> --count 85 `
>> --out output_spoo2 `
>> --force-select-chart `
>> --force-select-circles
```
### 2、用视觉数据库进行映射 批量校色
```powershell
python render_from_combined_mapping_fixed3.py `
>> --corrected output_spoo2\02_corrected.png `
>> --samples-csv output_spoo2\corrected_samples.csv `
>> --circle-file output_spoo2\visual_circles_manual.json `
>> --mapping output_combined\visual_mapping_T_poly2\visual_mapping_T.json `
>> --out output_spoo2\03_auto_visual_preview.png
```
### 3、对个别校色不理想色系进行手动微调（参数在csv文件）
```powershell
python render_from_combined_mapping_fixed4.py `
>> --corrected output_spoo1\02_corrected.png `
>> --samples-csv output_spoo1\corrected_samples.csv `
>> --circle-file output_spoo1\visual_circles_manual.json `
>> --mapping output_combined\visual_mapping_T_poly2\visual_mapping_T.json `
>> --background-mode original `
>> --original-photo data\spoo1.jpg `
>> --override-csv spoo1.csv `
>> --out output_spoo1\03_auto_visual_preview_tuned.png
```
